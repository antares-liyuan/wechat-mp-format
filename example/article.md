# 示例：用 Markdown 写公众号文章

> 这是一段导语，会显示成浅底的提示框。

写公众号最麻烦的是排版：编辑器不认 Markdown，粘贴过去全是井号和星号。这个工具把 Markdown 转成**带内联样式的 HTML**，粘贴即成品。

## 一、支持哪些格式

- **加粗**、二级和三级标题
- 引用、无序列表、有序列表
- 表格和插图（带图注）

## 二、一张表格

| 写法 | 效果 |
|---|---|
| `## 标题` | 带左侧竖条的小标题 |
| `> 引用` | 浅底提示框 |
| `**加粗**` | 深色加粗 |
